# docs

Design notes and specs for the app: what it is, how it works, what has been decided.

Name each spec `SPEC-<topic>.md` (for example `SPEC-app.md`), register it in `curated.docs` in
[`links.json`](links.json), and list the code it describes in `curated.covers`. Number the sections
(`## 1. Overview`, `## 2. Data model`). Code can then cite `SPEC-app §2`, and doclinks will name the doc
for review whenever that code changes. See [`../tools/README.md`](../tools/README.md).
